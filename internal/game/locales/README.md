# Локализация карт

`ru.json` и `en.json` — названия и краткие объяснения
42 карт базового набора на русском и английском. Описания пересказывают действие карты, а не
подменяют её художественное изображение или полный текст правил.

- Ключи (`robb-stark`, `aeron-damphair` и т. п.) — постоянные игровые ID.
  Не переименовывайте их при правке перевода: ID используются в сохранениях.
- `name` — подпись в руке, на карте, в выборе и журнале.
- `description` — подсказка в просмотре и выборе боевой карты.
- Тексты не исполняются. Логика находится в `../card_effects.go`; локализация
  сама по себе не включает способность. Поддержка помечается реестром движка.
- `../card_effects_test.go` проверяет базовый набор и взаимодействия.

`en.json.messages` переводит сообщения существующего Go-движка на границе
HTTP/WebSocket. Канонические сохранения и игровые ID не меняются. Ключи сообщений
одинаковы в RU/EN (`errors.notYourTurn`, `events.roomCreated`, `effects.cardCancelled`).
Русские значения соответствуют каноническим сообщениям движка;
длинные фразы заменяются раньше коротких.
Пользовательские имена и названия комнат не переводятся.
`../localization_test.go` проверяет все базовые карты, ошибки движка и отсутствие
мутаций состояния при переводе. API выбирает язык через `?lang=ru|en` или
`Accept-Language`; параметр URL приоритетнее заголовка. Неизвестный язык — русский.

Список реальных ограничений боевого движка сохраняется в корневых README/PLAN.
Основной источник уточнений взаимодействий — официальный FAQ 2.0 издателя,
ссылка на который есть в `docs/rules/catalog.json` от корня проекта.
