# Tides of Battle / карты перевеса

Текущие шесть лиц — подготовленные пользователем HD PNG (обновление 22.10.2026),
примерно 1000×1560 px. Старые маленькие изображения из Swords and Ravens больше
не используются. Пользовательские PNG остаются неизменными; `artwork:index`
создаёт рядом `.webp` в полном исходном разрешении (quality 92, alpha quality 100).
Браузер загружает WebP и сохраняет исходные пропорции, без обрезки.
Художественные материалы имеют отдельные права; лицензия
GPL исходного кода не разрешает их автоматическую публичную публикацию.
Как и остальные `local-assets`, эта папка подключается только read-only volume
и не включается в Docker-образ. Интерфейс сохраняет числовое представление, если
изображений нет.

Изображение — лицо карты, не отдельная физическая копия. Движок создаёт колоду из
24 копий: `zero` ×8, `sword` ×4, `fortification` ×4, `two` ×4, `three` ×2, `skull` ×2.
Состав и типизированные ID: `internal/game/tides.go` в основном проекте.

Размеры, размеры файлов и SHA-256-префиксы исходных PNG и подключённых WebP:
`web/src/artwork/index.json`.
Версия в URL исключает старую картинку из кэша; после следующей замены PNG
выполните `pnpm --dir web artwork:index` и пересоберите образ. `TestTidesBrowser` сверяет все шесть
доступных WebP, их фактический формат и размеры с этим описанием. Без локальных файлов UI сохраняет
числовой fallback; сбой одного изображения не блокирует загрузку другой карты.
