## Выбор перед стартом

В настройках создания комнаты и в меню настроек лобби выбирается число **домов**,
то есть людей и ботов вместе. По умолчанию шесть. Для одиночной игры можно
выбрать, например, три дома: один человек и два бота.

| Домов | Допустимые дома | Нейтральных числовых жетонов | Двор: звёзды по местам |
| --- | --- | --- | --- |
| 3 | Старк, Ланнистер, Баратеон | 2 + непреодолимые области | 3 / 2 / 1 |
| 4 | Предыдущие + Грейджой | 12 | 3 / 2 / 1 / 0 |
| 5 | Предыдущие + Тирелл | 9 | 3 / 3 / 2 / 1 / 0 |
| 6 | Предыдущие + Мартелл | 2 | 3 / 3 / 2 / 1 / 0 / 0 |

Нейтральные жетоны и закрытые области берутся из базового setup каталога,
не создаются произвольно по отсутствующим игрокам. В трёхдомной расстановке
12 сухопутных областей непреодолимы, вместе с четырьмя связанными портами.
В остальных вариантах закрытых областей нет. Стартовые армии и контроль
исключённых домов отсутствуют; треки сдвигаются без пустых мест.

Используется стартовый флот Ланнистеров по FAQ 2.0, включая корабль в порту
Ланниспорта во всех расстановках. Импортированное из community-каталога поле
`removedUnits` для трёх игроков не применяется: это не отдельное правило
из выбранной официальной эрраты.

Уже подключённого человека нельзя молча исключить сокращением числа домов:
сначала он должен выбрать разрешённый дом. После старта менять расстановку
нельзя. Добавляемые при расширении лобби места заполняются ботами; оставшиеся
места сохраняют своих игроков/настройки.

В лобби поле показывает серверный `setup` (армии, контроль, треки), а не
постоянную картинку расстановки на шесть домов. Начало матча использует тот же
генератор. Звёзды затем зависят от текущей позиции на треке, включая результат
торгов и способностей, а не от стартового дома.

## Три разных типа защиты

- `garrison`: гарнизон играющего дома на родной территории. Добавляет защиту,
  даже без отрядов инициируется нормальный бой с картами. Не является отрядом,
  не получает приказов, не поддерживает соседей, не расходует снабжение.
  Поражение удаляет его навсегда; возвращение контроля дома его не восстанавливает.
- `neutral`: числовая нейтральная сила. Для входа достаточно сравнять силу
  отрядов, похода и собственной поддержки. Осадные орудия учитываются против
  замка/крепости, в том числе из поддерживающей армии. Нет карт домов,
  перевеса или применения Меча. После захвата жетон удаляется.
- `blocked`: непреодолимое сопротивление. Вход запрещён независимо от силы,
  нельзя отступить или собрать войска в этой области. Порты закрытых областей
  тоже недоступны. Предпросмотр целей и настоящая команда используют общий запрет.

`View.fortifications` содержит тип, силу и дом (только для гарнизона).
На поле видны щиты/числа/гербы либо замок с ∞; правая панель объясняет правило.
Состояние берётся из сохранения, поэтому побеждённые жетоны не возвращаются при reload.

## Меч без перевеса

После раскрытия карт и немедленных способностей участвующий в бою текущий
владелец Меча получает сохраняемое решение `card_effect`, `kind: "blade"`:

```json
{"type":"ability","choice":"strength","revision":42}
```

Либо `choice: "keep"`, чтобы сохранить Меч. Расход происходит только при
подтверждённом +1. Отказ в этом бою не расходует право на следующий бой раунда.
Бонус добавляется отдельно от силы карты дома и виден в отчёте.

Используется тот же `Match.BladeUsed`, что у замены карты перевеса и +1 с
перевесом: только одно применение за раунд. Смена владельца не обновляет
жетон; новый раунд обновляет. Меч третьего, не участвующего дома не предлагается.
Мягкий таймер не решает за человека, жёсткий выбирает сохранение; боты выполняют
свой выбор через тот же валидатор. Решение/дедлайн переживают SQLite restart.

Это не закрывает PLAN G: последовательный показ всех нападений и удобный
разбор источников силы, особенно у боя на границе Вестероса, остаются отдельной задачей.
