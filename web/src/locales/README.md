# Переводы интерфейса

`ru.json` и `en.json` содержат одинаковые стабильные смысловые ключи:
`room.create`, `game.start`, `cards.close`. В компонентах используется
`t("room.create")`, а тексты находятся только в словарях. Это не замена текста в DOM.
Подстановки `{p0}`, `{p1}` передаются объектом вторым аргументом и выводятся React
как текст, без HTML и выполнения кода.

Для нового текста добавьте одинаковый ключ в оба словаря, затем вызов `t()`.
Правка перевода не требует менять ключ и вызовы. Ключи типизированы из `ru.json`:
опечатка или отсутствующий ключ обнаруживается при TypeScript-сборке.
Не переводите игровые ID, пути к ассетам и введённые пользователем данные.
Не вычисляйте перевод на уровне модуля: он должен обновляться при смене языка.
Подписи областей используют `regionName()`: русский справочник / исходные английские имена.

`pnpm test` проверяет наличие переводов для каждого вызова `t()`, совпадение ключей
и подстановок. Каталог карт и системные сообщения находятся отдельно:
`internal/game/locales/ru.json` и `en.json`.

Модуль Вестероса и одичалых имеет отдельные типизированные словари
`../events/ru.json` / `en.json` и `eventText()` из `events/model.ts`. Они используют
тот же личный язык и безопасные текстовые подстановки. `events/model.test.ts`
проверяет совпадение ключей/параметров и покрытие всех карт, решений и enum сервера.

Настройка языка личная, хранится в `localStorage.westeros-language`.
При отсутствии сохранённого выбора можно открыть `/?lang=en`.
Смена языка не меняет комнаты, права, ревизии и таймеры. Для сервера клиент
отправляет `Accept-Language`, для WebSocket — `?lang=`; на смене языка соединение
переоткрывается с тем же идентификационным cookie.
